# Tawfeer توفير — UAE Trip Reduction Platform

**Submitted to DAST 2026 — Dubai Award for Sustainable Transport, 14th Edition**

Every government question answered digitally is a car trip that never happened.
Tawfeer measures that impact across all 7 UAE emirates.

## Stack
- Node.js + Express
- Groq API (llama-3.1-8b-instant)
- Supabase (PostgreSQL)
- Playwright (tests)

## Setup
```bash
npm install
cp .env.example .env
# Add GROQ_API_KEY, SUPABASE_URL, SUPABASE_SERVICE_KEY, ADMIN_KEY
npm start
```
